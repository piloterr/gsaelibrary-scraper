# GSA eLibrary Scraper API – code examples

Examples for every GSA eLibrary endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/contract.sh`](curl/contract.sh) | `bash contract.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/contract.php`](php/contract.php) | `php contract.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Contract.cs`](csharp/Contract.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/contract.go`](go/contract.go) | `go run contract.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/ContractExample.java`](java/ContractExample.java) | `java ContractExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/contract.rb`](ruby/contract.rb) | `ruby contract.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/contract.mjs`](nodejs/contract.mjs) | `node contract.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
